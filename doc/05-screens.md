# 画面

[← 目次に戻る](README.md)

## 画面一覧

| 画面 | URL | ログイン | 内容 |
|---|---|---|---|
| ログイン | `/login` | 不要 | ユーザー名・パスワード（[認証](03-auth.md)） |
| サインアップ | `/signup` | 不要 | ユーザー名・パスワードで新規登録 |
| ホーム（入り口） | `/` | 必要 | DBでお気に入りトピックを見て、一番左のトピックのページへ移動する。お気に入りが0個なら `/topics?welcome=1` へ移動する |
| ホーム（ニュースフィード） | `/topics/[slug]`（例：`/topics/nextjs`） | 必要 | トピックバー ＋ NEW / READ / BOOKMARK タブ ＋ 記事一覧 |
| トピック設定 | `/topics` | 必要 | お気に入りトピックの選択。初回は `/topics?welcome=1` |

- 設定画面・ハンバーガーメニューは作らない
- ブックマーク専用の画面は作らない。ブックマークした記事は、ホーム（ニュースフィード）のBOOKMARKタブで見る
- ナビ（ヘッダー・下タブ）に「BOOKMARK」への独立したリンクは置かない。トピックページを開けば常にBOOKMARKタブが見えているため、別リンクは冗長と判断した（検討の経緯は [フロントエンド・バックエンドの構成](10-structure.md#bookmarkタブへのナビショートカットを見送った理由) を参照）

## 画面遷移

```
/signup ──（登録成功）──▶ /topics?welcome=1 ──（保存）──▶ /topics/[slug]

/login ──（ログイン成功）──▶ /

/ ──（お気に入り0個）──▶ /topics（初回）──▶ /topics/[slug]
│
└──（お気に入りあり）──▶ /topics/[slug]

/topics/[slug] ⇄ /topics （ヘッダーのリンク／下のタブ）
/topics/[slug] の中で NEW / READ / BOOKMARK タブを切り替える（ページ遷移なし）
```

## 共通レイアウト

### ログイン後（`/login`・`/signup` 以外）

- ヘッダー：左にアプリ名、右に **TOPICS / ログアウト** のリンク（PC）
- スマホ（画面幅 1024px 未満）：画面下に **HOME / TOPICS** のタブを固定表示する。ログアウトはヘッダー右上に置く
- 初回のトピック設定（`?welcome=1`）では、下のタブ・ヘッダーのリンクを出さない（トピックを選ぶまで先に進めないため）
- フッターに「記事の出典：Zenn」と「本アプリは Zenn 公式とは関係ありません」を明記する
- 配色は白と黒で統一する（アクセントカラーは使わない）

### ログイン画面（`/login`）

- ヘッダー：アプリ名のみ
- ユーザー名・パスワードの入力欄と、ログインボタン
- 「アカウントを作る」リンクで `/signup` へ

### サインアップ画面（`/signup`）

- ヘッダー：アプリ名のみ
- ユーザー名・パスワード・パスワード（確認用）の入力欄と、登録ボタン
- 「すでにアカウントをお持ちの方はこちら」リンクで `/login` へ

## 画面ごとの詳細

### ホーム（ニュースフィード）

#### スマホ（画面幅 1024px 未満）

```
┌────────────────────────────────┐
│ Zenn News                      │ ← ヘッダー
├────────────────────────────────┤
│ [●Next.js][Laravel][AWS][Pyt   │ ← トピックバー（横スクロール）
├────────────────────────────────┤
│  NEW 18  │  READ 9  │  BM 2    │ ← タブ
├────────────────────────────────┤
│ Next.js 16で実装する           │
│ SEO最適化のベスト...           │ ← 記事カード
│ (👤) sora · 9/23 14:05      🔖│
├────────────────────────────────┤
│ 記事の出典：Zenn               │ ← フッター
├────────────────────────────────┤
│      🏠 HOME      │    🏷 TOPICS     │ ← 下のタブ（画面下に固定）
└────────────────────────────────┘
```

#### PC（画面幅 1024px 以上）

```
┌──────────────────────────────────────────────┐
│ Zenn News                           TOPICS    │
├────────────┬─────────────────────────────────┤
│ MY TOPICS  │  NEW 18  │  READ 9  │  BM 2      │
│            ├─────────────────────────────────┤
│ ● Next.js  │ Next.js 16で実装する...          │
│   Laravel  │ (👤) sora · 9/23 14:05        🔖 │
│   AWS      │                                 │
└────────────┴─────────────────────────────────┘
```

- PC では横スクロールのトピックバーの代わりに、左サイドバーにお気に入りトピックを縦に並べる（並び順は選んだ順）
- スクロールしても、トピックバーとタブ（スマホ）、サイドバーとタブ（PC）はヘッダーの下に固定して表示する
- 選択中のタブ／トピックは、背景を薄いグレーにして示す

#### 仕様

| 項目 | 仕様 |
|---|---|
| お気に入りトピックが0個の場合 | トピック設定の初回画面（`/topics?welcome=1`）へ移動する |
| トピックの切り替え | トピックごとにURLが変わる（`/topics/nextjs` → `/topics/react`）。ブラウザの「戻る」で前のトピックに戻れる |
| 最初の表示 | 記事一覧はISRのキャッシュからすぐ表示できる。既読・🔖の状態は`useReadArticles`・`useBookmarks`（TanStack Query）がクライアントで取得した後に反映される（一瞬NEWとして表示されてからREADに切り替わることがある。[記事の取得](04-article-fetch.md#既読ブックマーク状態の反映クライアント側) 参照） |
| 記事カード：タイトル | 最大3行。はみ出した分は「…」で省略する。サムネイル画像・絵文字は使わず文字のみで構成する |
| 記事カード：ブックマーク | 未登録は枠線のみ、登録済みは塗りつぶし |
| 記事カード：タップ時 | Zennの記事を新しいタブで開き、既読にする（APIを非同期で呼ぶ） |
| 読んだ直後のカード | その場で薄く表示して残す。タブまたはトピックを切り替えたときにNEWから消え、件数も更新する |
| BOOKMARKタブ | 既読・未読の見た目の区別はしない |

### トピック設定

```
┌────────────────────────────────┐
│ Zenn News                      │
├────────────────────────────────┤
│ 興味のあるトピックを選択         │
│                                │
│ 開発言語             2/10 選択中│
│ [✓TypeScript][PHP][Python][Go] │
│                                │
│ インフラ・クラウド    1/10 選択中│
│ [✓AWS][Docker][Google Cloud]...│
├────────────────────────────────┤
│        [  保存する  ]          │
└────────────────────────────────┘
```

| 項目 | 仕様 |
|---|---|
| トピックの並び | カテゴリごとに表示する |
| 選択数 | カテゴリ名の右に「◯/◯ 選択中」を表示する |
| 見た目 | 選択中：黒地に白文字＋チェックマーク／未選択：白地に枠線 |
| 選択の順番 | タップした順が、そのまま「選んだ順」になる |
| 保存ボタン | 1つも選んでいないときは押せない（グレー表示） |
| 保存の仕組み | 保存ボタンで`useFavoriteTopics`のmutationが`PUT /api/me/favorite-topics`を呼び、DBの`users.favorite_topics`を置き換える |
| 初回（`?welcome=1`） | 下のタブ・ヘッダーのリンクを出さない。保存するまでほかの画面に移動できない |
| 保存後の移動先 | 一番左（最初に選んだ）トピックのホームへ移動する |

### ブックマークの確認

- 専用画面は作らない。ホーム（ニュースフィード）のBOOKMARKタブで、自分のブックマークを一覧表示する（ブックマークした日時が新しい順、Zenn APIへのアクセスは発生しない）
- ナビからの直接リンクは置かない。見たいトピックのページを開き、BOOKMARKタブに切り替えて確認する

## 空の状態

| 状況 | 表示する文言 |
|---|---|
| NEWが0件 | 「新着記事はありません」 |
| READが0件 | 「まだ読んだ記事はありません」 |
| BOOKMARKが0件 | 「ブックマークした記事はありません。🔖を押すと、ここに保存されます」 |

## 読み込み中・エラー

| 状況 | 動き |
|---|---|
| 記事一覧の読み込み中 | ISRのキャッシュがあれば即表示。初回アクセスで未キャッシュの場合のみ、生成中の待ち時間が発生する |
| 既読・🔖の取得中 | 記事一覧は先に表示し、取得が終わるまでは全記事をNEW扱いで表示する（取得完了後にREAD/BOOKMARKへ切り替わる） |
| Zenn APIの取得に失敗 | 「記事を読み込めませんでした」と「再読み込み」ボタンを表示する |
| ブックマークが上限の100件 | トーストで「ブックマークは100件までです。いくつか外してください」と表示する |
| DBへの書き込みに失敗 | トーストで「保存に失敗しました。もう一度お試しください」と伝える |
| 存在しないページ（404） | 「ページが見つかりません」と、ホームへ戻るボタンだけのシンプルな画面 |
| 未ログインでページを開いた | `/login` へ移動する |
| ログインの有効期限切れ・Cookie無効 | `/login` へ移動する |
| ログイン失敗 | 「ユーザー名またはパスワードが違います」と表示する（どちらが違うかは示さない） |
| サインアップ時にユーザー名が重複 | 「そのユーザー名は既に使われています」と表示する |
