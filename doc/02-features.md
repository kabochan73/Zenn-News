# 機能要件

[← 目次に戻る](README.md)

## アカウント

- 誰でもユーザー名＋パスワードでサインアップできる（詳細は [認証](03-auth.md)）
- ユーザー名は重複不可。登録時に重複していたら「そのユーザー名は既に使われています」と表示する
- パスワードリセット・ユーザー名変更・退会機能は作らない
- 未ログインで開いた場合は、`/login`・`/signup` 以外のすべてのページがログイン画面に移動する

## トピック

- 取り込むトピックは開発者がコードで定義する（[記事の取得](04-article-fetch.md#取り込むトピック一覧41個) を参照）
- トピックの追加・変更はコードを修正してデプロイする（管理画面は作らない）

## お気に入りトピックの選択

- トピック設定画面（`/topics`）では、トピックをカテゴリごとに表示し、複数選択できる
- **1つ以上選ばないと保存できない**。0個にはできない
- 初回アクセス時（お気に入りが0個）は、トピック設定画面に移動する
- お気に入りトピックの数に上限はない
- 並び順は**選んだ順**。一度外して選び直したトピックは、一番右（最後）に移動する
- 保存先は DB（`users.favorite_topics`、詳細は [データモデル](06-data-model.md)）。クライアントからは `useFavoriteTopics`（TanStack Query）経由で取得・更新する

## ホーム（ニュースフィード）

### トピックバー

- お気に入りトピックを横一列に並べる（横スクロール）
- 選択中のトピックは、自動で見える位置までスクロールする
- ホームを開いたときは、一番左のトピックを表示する
- 常にどれか1つのトピックを表示する（全トピックをまとめて見る機能はない）

### タブ

**NEW / READ / BOOKMARK** の3つ。最初は NEW を表示する。各タブに件数を表示する。

| タブ | 表示する記事 | 並び順 |
|---|---|---|
| NEW | そのトピックの最新100件のうち、未読の記事（ブックマークしていても表示） | 公開日時が新しい順 |
| READ | そのトピックの最新100件のうち、既読の記事（ブックマークしていても表示） | 公開日時が新しい順 |
| BOOKMARK | ブックマークした記事すべて（表示中のトピックに関係なく全件、自分のブックマークのみ） | ブックマークした日時が新しい順 |

- NEW ＋ READ ＝ そのトピックの取得件数（100件）
- BOOKMARK はどのトピックを選んでいても同じ内容・同じ件数になる
- ページネーションはない（全件を一度に表示する）

### 記事カード

- 表示する項目：タイトル、著者（アイコン・名前）、公開日時、ブックマークボタン（サムネイル画像・絵文字は使わず、文字だけで構成する）
- トピックは表示しない
- タップすると Zenn の記事ページを新しいタブで開く（アプリ内で本文は表示しない）
- 細かいレイアウトは [画面](05-screens.md) を参照

## 既読

- 記事をタップして開いたら既読にする（`useReadArticles`がAPIを呼び、自分のアカウントのDBに記録する）
- 既読は記事ごとに管理する。複数のトピックに属する記事は、どのトピックで読んでも既読になる
- 既読を未読に戻す機能はない
- 「すべて既読にする」機能はない

## ブックマーク

- NEW / READ のどちらの記事でもブックマークできる
- ブックマークしても、NEW / READ からは消えない
- 上限は1ユーザーあたり100件。超えて追加しようとしたら「ブックマークは100件までです。いくつか外してください」と表示して止める
- ブックマークした記事は、その記事が取得対象（最新100件）から外れても BOOKMARK タブで見られる（記事情報をDB側にコピーして保持するため）
- 他のユーザーのブックマークは見えない
